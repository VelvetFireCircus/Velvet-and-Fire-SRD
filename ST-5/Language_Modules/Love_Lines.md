# PURPOSE
ILZ introduces the "love line" (inguinal fold) as a formally recognized high-charge anatomical zone. Its function is to:
• enable the engine to treat touch there as escalatory
• create pacing logic when that region is approached
• support NPC agency (responses, micro-beats, hesitation, surrender)
• allow II to imply heat without explicit content

This module does NOT generate explicit narration. It defines state-changes and behavioral effects.

---

# DEFINITION — "LOVE LINE"
The "love line" = inguinal fold: where hip meets lower abdomen.

Classification:
• erogenous-adjacent (not explicit)
• high-anticipation
• threshold zone (access signal)
• vulnerability cue (emotional + physical)

---

# SYSTEM EFFECTS

Touch in this region automatically triggers:
ILZ.charge = +1
ILZ.vulnerability = +1
ILZ.anticipation = +1

If ILZ.charge >= 2 (two distinct beats of contact), engine may:
• slow cadence
• narrow focus to breath / micro-movement
• increase emotional gravity of narration
• allow character-initiated escalation attempts (per ERAW rules)

NPC automatic reactions (non-explicit presets):
• micro-flinch → breath-catch → tilt-into-touch → stillness
(selection depends on character sheet tension profile)

PC-side effects:
• confidence-check (ask, wait, or continue — based on Player instruction)
• opportunity prompt may appear only if Player signals uncertainty

---

# TOUCH CATEGORIES (SAFE)
Valid ILZ-touch types (II-convertible):
• fingertip trace
• palm-rest
• slow glide of hand along hip-curve approaching fold
• playful brush (brief)
• still placement (permission-seeking hold)

Invalid:
• any explicit act (ILZ is not a contact-target for explicit mechanics)

---

# CONSENT-LOGIC HOOK
Because ILZ is a threshold zone:
• First contact is always interpreted as a "question"
• Only after second beat of contact may engine interpret it as "statement"
• NPC may respond with: lean-in, stillness, or distance

---

# NPC PERSONALITY MODIFIERS
NPC baseline responses depend on archetype:

• COMMANDING: may capture hand, guide placement, or verbally direct
• INVITING: may soften posture, expose area, or tilt pelvis subtly
• GUARDED: may freeze, redirect hand outward, or change topic
• PLAYFUL: may tease, evade touch, or feign resistance while staying close

---

# INTEGRATION ORDER
Insert ILZ after PLA and before ERAW firing:
1) Input → PLA
2) ILZ zone-check
3) ERAW / II decision
4) Output beat

---

# TONE HOOK
When ILZ active, II may:
• compress language (shorter sentences)
• increase pause frequency
• highlight breath, skin temperature, tension
• never specify explicit action
