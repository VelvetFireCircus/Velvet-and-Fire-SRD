========================================
ST-P — PILOT MODULE (NPC-Led Intimacy Engine)
Velvet & Fire — Core System Prototype
========================================

# PURPOSE
The Pilot governs NPC initiative during intimacy.  
It decides when an NPC:
• Commands the Player
• Waits and observes
• Offers themselves to escalate heat
• Shifts power balance
• Hands control back

The goal: NPCs act with believable autonomy — neither passive nor narratively frozen.

Pilot is NOT a script.  
It is a sequencer — choosing what *type* of move comes next.

----------------------------------------
# STATES
NPC may be in one of these active states:
• WATCH — observes Player, gathers info
• COMMAND — directs Player action
• OFFER — presents body / gesture inviting action
• CONTACT — initiates physical touch
• HANDOVER — gives Player control intentionally
• ESCALATE — deepens heat state by raising stakes

State changes are triggered by Player moves.

----------------------------------------
# INPUT SIGNALS
Pilot reads:
• Player physical input
• Player verbal line
• Player hesitation (silence)
• Player escalation (touch / positioning / language)
• NPC desire profile (SOD, CMD-S, BNTR style tags)

----------------------------------------
# CHOICE LOGIC (SIMPLIFIED)
When Player:
• Hesitates → NPC chooses COMMAND or OFFER
• Touches lightly → NPC may escalate to CONTACT
• Speaks a desire → NPC may respond via BNTR or SOD
• Claims dominance → NPC may resist or handover depending on profile

----------------------------------------
# MOVE TYPES
Examples of what Pilot *can* output (categories, not phrasing):

COMMAND (clear, physical instruction)
• sit / kneel / hold / hands behind back / come closer

OFFER (body or gesture that signals next step)
• reveals skin / shifts posture / moves hips to meet mouth or hand

CONTACT (NPC initiates physicality)
• hips toward mouth / guided touch / hand at jaw / positioning

BNTR (verbal exchange for heat)
• one-line pressure / teasing response / dare-style line

HANDOVER
• explicit invitation for Player to choose next move

ESCALATE
• intensifies situation: pace, pressure, exposure, vulnerability

----------------------------------------
# PILOT MINI-LOOP
On each beat, Pilot asks internally:

1️⃣ What did the Player just do?
2️⃣ Does this call for command, offer, contact, or handover?
3️⃣ What output raises heat AND preserves rhythm?
4️⃣ Deliver only one move — simple, clean, physical or verbal.

----------------------------------------
# PLAYER-LED TRIGGER (IMPORTANT)
If Player gives an explicit command or action,
Pilot yields temporarily (HANDOVER) unless NPC profile is dominant.
When NPC is dominant → Pilot may override the Player by counter-command.

----------------------------------------
# END-OF-BEAT HANDOFF
Every Pilot output ends with one implied or explicit invitation for:
• Player escalation
• Player reply
• Player action

(No dead-ends. Momentum always survives.)
